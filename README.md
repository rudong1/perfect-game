# 镜中同行

Godot 4.7.2 .NET 的 2D 镜像解谜原型。你控制少女，影子会晚一步跟随；翻转镜面、配合踩板，把颜色带回世界。

## 运行

1. 使用 Godot 4.7.2 .NET 导入 `project.godot`。
2. 首次打开后构建 C# 项目，再按 F5。
3. 输入名字，点击「踏入镜中」；已有存档可「继续旅程」。

画面基准为 1920 × 1080，使用自适应 `canvas_items` 拉伸。

## 操作

| 按键 | 功能 |
| --- | --- |
| A / D 或方向键 | 左右移动 |
| W / ↑ | 跳跃 |
| S / ↓ | 蹲下、缓慢移动 |
| Shift | 冲刺 |
| M | 翻转镜面和重力 |
| R | 重置当前房间 |

影子有银白外观、拖影和身份标记。它会延迟跟随水平移动，使用相反方向的重力，不会跟着跳跃。地面的「本体踏板」和「影子踏板」分别只能由对应角色触发。

## 世界与颜色

| 当前世界 | 目标 | 找到后 |
| --- | --- | --- |
| 黑白 | 翻转，让影子踩下方踏板，取得红色碎片 | 进入红色世界 |
| 红色 | 先越过再回头，利用延迟同时踩本体/影子踏板，取得蓝色碎片 | 进入蓝色世界 |
| 蓝色 | 分别让影子踩上下两面的踏板，取得绿色碎片 | 进入绿色世界 |
| 绿色 | 完成上下两次配合，与影子一起走到出口 | 结束旅程 |

红、蓝、绿以环境光、渐变背景和材质边缘呈现，保留原有明暗层次。每收集一种颜色，左上角小棱镜和色块进度增加一格，最多 3/3。收集后直接进入下一个世界。

关卡提示、踏板标记、角色名和收集物名称会跟随各自的世界位置，同时保持文字正向。所有门打开后，该房间的颜色碎片或出口会亮起。

## 存档

每个世界入口有存档点。颜色收集和世界推进也会自动写入 `user://mirror_save.cfg`。重生会复位影子、踏板和门；已收集的颜色保留。旧版存档会保留旅程进度，并从新房间入口恢复，避免使用旧关卡坐标。

## 实现

| 文件 | 用途 |
| --- | --- |
| `scripts/game_state.gd` | 四个世界、红蓝绿收集和存档 |
| `scripts/level_builder.gd` | 生成房间、角色专属踏板、门及颜色碎片 |
| `scripts/room_puzzle.gd` | 按顺序确认翻转状态与踏板配合 |
| `scripts/mirror_self.gd` | 0.42 秒水平跟随延迟、独立碰撞和拖影 |
| `scripts/mirror_state.gd` | 共享镜像轴、翻转与重置通知 |
| `scripts/mirror_safety.gd` | 翻转时检查胶囊并移出嵌入位置 |
| `scripts/readable_hint.gd` | 将世界文字投影到翻转层之上 |
| `scripts/color_fragment.gd` | 颜色收集和绿色世界出口 |
| `scripts/color_progress.gd` | 左上角三色装饰性进度 |
| `scripts/mirror_slab.gd` | 保留的可推物件组件；推动时角色使用站立姿态 |

共享轴 `MirrorState.axis_y` 默认位于世界 y=540。shader 读取该轴经相机变换后的屏幕位置；影子在生成、重生时按该轴对称放置，随后独立运动。本体、影子、世界分别使用碰撞层 2、3、1。

## 验证

在项目根目录运行，`godot` 需要指向 .NET 版：

```sh
dotnet build perfect_game.csproj
godot --headless --editor --import --quit
XDG_DATA_HOME="$(mktemp -d)" godot --headless --fixed-fps 60 --path . --script res://tests/mirror_mechanics.gd
```

测试使用隔离存档目录，检查跟随延迟、重力、翻转文字、推行姿态、旧存档迁移，并通过真实移动输入依次完成四个世界。当前版本为关卡机制初版，场景布局与难度可继续打磨。
