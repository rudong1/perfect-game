# 镜尽余色

镜面碎了，颜色不再属于你。可这一次，留下的不再只是一个名字。

Godot 4.7.2 标准版的 2D 镜像解谜游戏。少女与晚半拍的分身走进同一座哥特教堂，通过分身配合、推镜传送和棱镜光路找回颜色。

## 运行

1. 使用 Godot 4.7.2 标准版导入 `project.godot`，等待素材导入后按 F5。
2. 输入名字并点击「踏入镜中」，在序章中按 Enter 或点击逐段阅读相遇的故事，再进入游戏。标题与序章使用女孩和倒影隔镜贴掌的哥特插画。
3. 已有存档可在标题画面选择「继续旅程」。

[标题实机画面](docs/title.png) · [序章实机画面](docs/opening.png)

游戏使用 GDScript，不需要 .NET 或 C# 构建。仓库保留的 Godot-MCP C# 编辑器插件默认关闭；需要该可选插件时，可自行使用 .NET 版编辑器并启用它。

画面基准为 1920 × 1080，拉伸模式为 `canvas_items`。四关恢复单屏布局。

## 操作

| 按键 | 功能 |
| --- | --- |
| A / D 或方向键 | 移动；贴近立镜时推动镜面 |
| W / ↑ | 跳跃 |
| S / ↓ | 蹲下 |
| Shift | 冲刺；推动镜面时保持稳定推行姿态 |
| M | 上下翻转画面与重力；光路关中同时转动最近一面反射镜 |
| E | 靠近立镜时穿到镜面的另一侧 |
| R | 重置当前房间 |

## 三种玩法与四个世界

| 世界 | 玩法 | 目标 |
| --- | --- | --- |
| 灰 · 双生门廊 | 三段分身接力 | 折返配合、换面前行、窄板回转，逐道解锁三扇门，取得红色 |
| 红 · 推镜廊 | 双板与双向校准 | 双板开栅门，先映向右侧，再反向校准映回左侧，取得蓝色 |
| 蓝 · 三色回响 | 影子封印、光路与出口双板 | 影子依次开上、下、上三枚封印，一同穿镜接通三色，再折返配合取得绿色 |
| 绿 · 最后的同行 | 首尾双板与共同穿镜 | 先完成入口配合，再由影子开光闸、两人穿镜，最后同时压住活光出口双板 |

分身延迟 0.42 秒继承水平移动，使用相反重力，不共享跳跃。上下踏板分别标明「本体」和「影子」；双板必须同时被对应角色压住，门才会打开。

跑动与冲刺共用新绘制的八帧摆臂循环，双手随步伐在胸前与身后交替，切换速度时保留动作相位。分帧读取原图的透明行间隔，避免切断鞋子或混入相邻动作；跳跃、落地和推镜姿态保留。

镜面自己的 x 是水平传送轴，出口位置遵循 `Vector2(2 * slab.x - entry.x, entry.y)`。出口被真实碰撞体挡住时会拒绝传送，并显示正向可读的提示。红色关卡的两个镜印按顺序显示，要求分别从左右两侧真正映到接引踏板，先传错再走过去不能代替对准。无色关卡在第二道门后存档，红色关卡在双板门后和第一道传送后存档。

光束沿实际反射线路抵达对应接收器。M 只转动角色附近的一面镜子；推动立镜会改变遮挡关系。两色接通时显示 2/3 的接近成功反馈，光路被重新遮断后门和收集物会再次锁住。光路状态与左上角的颜色收集进度相互独立。

后两关的红、绿、蓝光源各有一枚只能由影子踩亮的封印，分别位于上方、下方、上方。封印亮起后保持开启，重试时重置；本体踩上去不能代替她。后期立镜的 E 会把两人一起带到镜面另一侧，再恢复 0.42 秒延迟跟随。三束光接通后，出口仍需要本体与影子的双板配合；光束中断后须重新完成配合。

[影子封印实机](docs/shadow_seals.png) · [恢复容貌后的 darksky](docs/darksky.png)

世界按灰→红→蓝→绿推进，只收集红、蓝、绿三个颜色，进度最多 3/3。关卡提示、镜面提示、接收器名称和角色名字在画面翻转后仍保持正向可读。

每次真正取得颜色后，先播放对应的独立 CG，再进入下一个世界：红色是祭坛台阶前跪地捧晶，蓝色是雨水回廊中举晶映光，绿色是旋梯上护晶于胸。三张图的构图、动作和场景各不相同；镜中的女孩仍是银发倒影，在后方神情微冷地注视，没有提前变成复活后的容貌。过场暂停关卡，淡入后按 Enter 或点击继续；镜像、移动、穿镜、重置和开发跳关不会打断画面。收集后立即保存，中途退出后「继续旅程」会接着观看该 CG，确认后再进入下一关。

调试构建保留隐藏的 P 键：直接获得本关对应颜色、保存并播放收集 CG，确认后前进；最后一关只有出口，P 直接进入终幕，不增加第四种颜色。按住 P 不会连续获得颜色。此键不显示在游戏内。

## 场景

四个区域使用同一教堂构图的独立背景图。无色区悬着残缺的链条；红色区添上旧帷幔；蓝色区有雨痕、积水和流动薄雾；绿色区则让苔蔓爬过石墙，在回廊角落留下墓碑。四张背景已重新去除蜡烛、火焰与暖色光晕，程序烛光层也已移除；金色描边、镜框与存档符号统一为铅灰。彩色部分保留红、蓝、绿三种颜色家族。人物、分身、踏板、门和平台均由真实节点显示。

## 剧情与终幕

倒影曾相信找回教堂的颜色，就能找回自己的身体。出口开启后，她才发现自己已经不算活着的人，镜门认得的是主角身上的颜色；而她依附的巨镜一旦碎裂，她也会消失。出于恐惧，她伸手夺取颜色，试图重新成为活人。

终幕先通过过门失败、镜中近景、主角劝阻与倒影走出镜面来完成转折，随后交还移动控制。玩家向右逃跑，可用 Shift 冲刺；红、蓝、绿彩窗与光照共同铺满走廊，镜头、铺路、远景窗廊和近景拱柱一起移动。追逐光照读取已收集颜色，赠色后逐渐褪为灰白。撞碎巨镜时，原图中的金属镜框与玻璃一起化为带纹理的碎片。

碎镜后，镜背旧字揭示「夺来的色彩只能造出倒影，赠予的色彩才能唤回生命」。主角听完女孩被困的遭遇，主动交出一起找回的红、蓝、绿。库存真实清空，三色融合，镜中的女孩重获身体与温度，也恢复自己的墨蓝短发、蓝眼睛与宽袖哥特裙。游戏中的角色使用独立绘制的站立、伸手、拥抱、行走动作。复活、拥抱、携手离场各有一张新 CG，拥抱演出保留完整停顿，再交还对话控制。她在最后一句说出「……对了，我叫 darksky。」玩家在开场为主角命名，倒影的真名只在此刻揭晓。[完整剧情稿](docs/story.md)，[追逐实机画面](docs/finale.png)，[拥抱实机画面](docs/embrace.png)，[结局实机画面](docs/ending.png)。

追逐中被抓住或按 R 会从追逐入口重试，已经收集的颜色保留。存档点使用小型菱形印记，不再悬挂文字标签。

## 存档与验证

改名后沿用原有存档位置。入口及途中存档点、颜色收集和世界推进会写入 `user://mirror_save.cfg`。重生会清空穿镜、影子封印与光路状态。第 7 版存档分别记录赠色、复活与完成：追逐中退出回到追逐入口，赠色后继续融合，复活后继续团聚，拥抱与双人离场后才记录完整结局。继续游戏不会返还已赠出的颜色。旧版完成的复活存档会直接进入新版团聚与拥抱；旧版蓝绿关卡保留颜色及世界进度，并重置不适用的机关存档点。

使用标准版 Godot 在项目根目录执行：

```sh
godot --headless --editor --import --quit
XDG_DATA_HOME="$(mktemp -d)" godot --headless --fixed-fps 60 --path . --script res://tests/mirror_mechanics.gd
```
