# 镜尽余色 · 剧情稿

镜面碎了，颜色与那个名字留了下来。

很久很久以前，一个女孩掉进了镜面世界。

她走过教堂的每一条回廊，推过每一面镜子，却始终解不开出口前的谜。她等了太久，久到颜色褪去，伸向门环的手也只剩镜中的轮廓。

后来，她终于等来了第二个倒霉蛋。

那是另一个刚坠入镜面的女孩——由玩家为她命名，也是这一次旅程的主角。

「一个人走不出去的地方，就让两个人一起试试。」

先来的女孩把手贴上镜面，站到了主角的另一侧。

「从今天起，我就是你的倒影。」

她们借着错开半拍的脚步压住机关，推动镜面，接通光路。红色照暖了石墙，却仍穿过倒影的掌心。她说：「也许，等颜色全部回来就好了。」

蓝色回来以后，她又提起一个传闻：「听说镜门只记得活人的颜色。」她低下头，很快补了一句：「我们先把它们找回来。」

她相信，颜色回来，自己也能回来。

可当绿色也回到教堂，镜门终于回应主角时，她伸出的手依旧穿过了光。镜中留下了她的模样，门外却没有她的影子。

「原来，回来的只是教堂的颜色。我被留在这里太久了……已经不算活着的人。」

她望着主角身上的三束微光，终于明白镜门认出的是什么。

「门认得你身上的颜色，却认不出我。我只剩一道影子了。那面镜子一碎，我也会消失。」

主角回过身：「那我们再找一条路。说好一起走的——」

「你的颜色，也许能让我重新成为活人。我已经等过太多次了……这次，借给我吧。」

她松开镜中的门环，从一直隔在她们之间的镜面走下，站到了主角的身后。

「这一次，我不想再做留下的那个人。」

主角向右逃跑。窗廊与石柱向身后退去，走廊尽头的巨镜越来越近。倒影伸向那些找回的颜色，她已经听不进主角的呼唤。

主角没有停下，迎着镜面撞了过去。

巨镜碎裂。那些颜色仍绕在主角的身旁，身后的脚步声停了。

碎片纷纷坠落，最后一片镜子里，还留着那个女孩淡淡的轮廓。她没有再伸手夺取什么。

主角停下脚步：「刚才……你是真的想把我的颜色夺走吗？」

「是。门亮起来的时候，我以为终于轮到我了。可光穿过我的手，我忽然什么都听不见，只剩下害怕。」

「我也害怕。可我一直以为，身后那个晚半步的脚步声，是在陪着我。」

镜中的女孩垂下手。

「那是真的。第一次等到你，第一次有人回头找我……那些时候，我真的想和你一起出去。」

她的轮廓越来越淡，声音却没有再躲闪。

「后来，我只顾着不想再被留下，竟然想把你也留在这里。……对不起。」

主角沉默了一会儿。

「我现在还没办法说没关系。但一起走过的那些路，我也不会当作没有发生。」

「嗯。把颜色带走吧。别为了等我，错过外面的天亮。」

主角再次抬起手，贴向那片尚未落下的镜面。像她们相遇时一样，两只手掌隔着玻璃相对。这一次，主角已经感觉不到另一侧的重量。

「那至少告诉我……你的名字。」

镜中的女孩看着她，最后一次笑了。

「也许，这也算是不错的告别吧。」

「……对了，我叫 darksky。」

镜片映不出任何人了，主角仍把手停在那里，直到最后一点光也散去。

随后，她带着颜色走出了教堂。这一次，她记住了那个女孩的名字。

## 演出与关卡

- 游戏显示名与窗口标题为《镜尽余色》，沿用原有存档位置。
- 标题页与序章共用新生成的哥特镜面插画：女孩与倒影各抬一只手，隔镜贴掌；文字区使用暗色衬底。
- 无色区先教上下双板，再换面折返完成第二组配合；两段之间有无字存档印记。
- 红色区先推镜校准，再退到门槛印记，真正映到接引踏板。直接走过去踩板不能开门。
- 红、蓝、绿区域依次铺垫倒影没有恢复肉身、活人颜色的传闻，以及她过门失败。
- 终幕先淡入，再通过对白与镜中伸手失败的近景解释动机。镜头回到主角后，倒影才从另一侧走到她身后。
- 追逐使用新生成的远景与透明拱廊，两层随同一相机以不同速度滚动；巨镜与推镜立柱都使用独立生成的哥特美术。
- 碎镜由原图切分成带纹理的碎片，镜框与玻璃一起破碎。被追上会直接重试追逐，保留已经找到的颜色。
- 碎镜后保留十段告别：主角责问、倒影承认恐惧与伤害、道歉、主角保留自己的感受、相遇时贴掌动作的重现，以及逐渐消散。完成告别后先淡出离场，再记录完整结局。
- darksky 的名字只在最后一句告别中揭晓。
