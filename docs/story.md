# 镜尽余色 · 剧情稿

镜面碎了，颜色不再属于你。可这一次，留下的不再只是一个名字。

很久很久以前，一个女孩掉进了镜面世界。

她走过教堂的每一条回廊，推过每一面镜子，却始终解不开出口前的谜。她等了太久，久到颜色褪去，伸向门环的手也只剩镜中的轮廓。

后来，她终于等来了第二个倒霉蛋。

那是另一个刚坠入镜面的女孩——由玩家为她命名，也是这一次旅程的主角。

「一个人走不出去的地方，就让两个人一起试试。」

先来的女孩把手贴上镜面，站到了主角的另一侧。

「从今天起，我就是你的倒影。」

她们借着错开半拍的脚步压住机关，推动镜面，接通光路。红色照暖了石墙，却仍穿过倒影的掌心。她说：「也许，等颜色全部回来就好了。」

蓝色回来以后，她又提起一个传闻：「听说镜门只记得活人的颜色。」她低下头，很快补了一句：「我们先把它们找回来。」

她相信，颜色回来，自己也能回来。

可当绿色也回到教堂，镜门终于回应主角时，她伸出的手依旧穿过了光。镜中留下了她的模样，门外却没有她的影子。

「原来，回来的只是教堂的颜色。我被留在这里太久了……已经不算活着的人。」

她望着主角身上的三束微光，终于明白镜门认出的是什么。

「门认得你身上的颜色，却认不出我。我只剩一道影子了。那面镜子一碎，我也会消失。」

主角回过身：「那我们再找一条路。说好一起走的——」

「你的颜色，也许能让我重新成为活人。我已经等过太多次了……这次，借给我吧。」

她松开镜中的门环，从一直隔在她们之间的镜面走下，站到了主角的身后。

「这一次，我不想再做留下的那个人。」

主角向右逃跑。窗廊与石柱向身后退去，走廊尽头的巨镜越来越近。倒影伸向那些找回的颜色，她已经听不进主角的呼唤。

主角没有停下，迎着镜面撞了过去。

巨镜碎裂。那些颜色仍绕在主角的身旁，身后的脚步声停了。最后一片镜子里，还留着那个女孩淡淡的轮廓。

碎裂的镜框背后，露出一行从未被人看见的旧字：

「夺来的色彩只能造出倒影，赠予的色彩才能唤回生命。」

镜中的女孩垂下手。她说起自己也曾是一个迷路的人，说起解不开的出口与没有尽头的等待。她等到身体褪去，才明白自己已经被镜子留下了。

「你会回头找我，会等我跟上……我真的想和你一起走。可看见门只回应你，我又只剩下害怕。」

她没有再躲开主角的目光。

「我把陪伴变成了追赶，竟然想夺走属于你的东西。……对不起。我不该让你也尝到被留下的滋味。」

主角沉默了一会儿。

「我还在生气。可我不愿用你的消失，换我一个人的离开。」

她看向掌心的红、蓝、绿，再看向镜背的旧字。

「如果不能夺走，那就由我亲手给你。」

「可那是你一路找回的颜色。给了我，它们就不会再属于你了……你真的愿意？」

主角抬起手，像她们第一次相遇时那样，把掌心贴向镜中的另一只手。

「这些颜色，是我们一起找回来的。这一次，换我把你带回来。」

红色、蓝色、绿色依次离开她的掌心。三束光在镜中交汇，汇成完整的生命。围绕主角的颜色熄灭了，镜中女孩的轮廓却不再透明。

那只曾被光穿透的手，第一次有了温度。石地上，落下了第二道真实的影子。

「原来……被人握住手，是这样的感觉。我以为自己早就忘记了。」

「这一次，不用谁等在镜子里了。我们一起走。还有……我还不知道你的名字。」

女孩握紧她的手，笑了。

「……对了，我叫 darksky。」

主角不再拥有那些颜色。可这一次，她们真的一起走出了教堂。

## 演出与关卡

- 游戏显示名与窗口标题为《镜尽余色》，沿用原有存档位置。
- 标题页与序章共用新生成的哥特镜面插画：女孩与倒影各抬一只手，隔镜贴掌；文字区使用暗色衬底。
- 无色区包含三道双板门：先折返配合，再换面向右，最后回到地面折返对齐窄踏板；第二、三道门之间有无字存档印记。
- 红色区先完成双板栅门，再把镜子推到第一道刻度，映向右侧接引板；随后把镜子推回第二道刻度，从右侧映回左侧踏板。每次只显示当前需要的镜印。直接走过去踩板不能代替正确穿镜。
- 四关背景已重新去除蜡烛与火光，程序烛光层也已移除。石框、UI 与存档符号使用中性铅灰；彩色来源保留红、蓝、绿三种颜色家族。
- 红、蓝、绿区域依次铺垫倒影没有恢复肉身、活人颜色的传闻，以及她过门失败。
- 终幕先淡入，再通过对白与镜中伸手失败的近景解释动机。镜头回到主角后，倒影才从另一侧走到她身后。
- 追逐使用新生成的远景与透明拱廊，两层随同一相机以不同速度滚动；巨镜与推镜立柱都使用独立生成的哥特美术。
- 碎镜由原图切分成带纹理的碎片，镜框与玻璃一起破碎。被追上会直接重试追逐，保留已经找到的颜色。
- 碎镜后先揭示镜背关于「夺取」与「赠予」的旧字，再让女主听完她的遭遇。女主主动交出三色，库存清空，经过可见的融合演出才记录复活；女孩从烟状透明改为真实、不透明的身体。
- 复活与双人离场分别使用新生成的 CG。对话放在画面左侧，避开人物与交握的手。
- darksky 的真名只在复活后的最后一句团聚对话中揭晓。
- 赠色、复活、结束分别保存，继续游戏不会返还已赠出的颜色，也不会重复赠予。旧版完成存档可保留已收集的三色，进入新结局。
