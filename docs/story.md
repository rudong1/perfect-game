# 镜中同行 · 剧情稿

很久很久以前，一个女孩掉进了镜面世界。

她走过教堂的每一条回廊，推过每一面镜子，却始终解不开出口前的谜。后来，颜色一点点褪去，她也不再提起自己的名字。

她等了很久，终于等来了第二个倒霉蛋。

那是另一个刚刚坠入镜面的女孩——由玩家为她命名，也是这一次旅程的主角。

「一个人走不出去的地方，就让两个人一起试试。」

先来的女孩把手贴上镜面，站到了主角的另一侧。

「从今天起，我就是你的倒影。」

她们一同翻转教堂的上下，借着错开半拍的脚步压住机关，推动镜面，接通光路。红色回来时，倒影望着掌心停了很久；蓝色回来时，她低声说：「有了全部颜色，就能离开这里。」

她没有说，是谁能够离开。

当绿色也回到了教堂，最后的出口终于显现。那个总比主角晚半拍的脚步声，第一次追了上来。

倒影不再站在镜子的另一面。她来到主角身后，伸手抓向那些找回的颜色。

「对不起。我等得太久了。」

「把那些颜色给我。这一次，该轮到我出去了。」

主角转身向右逃跑。前方，一面巨大的镜子挡住了去路。身后的脚步越来越近，她没有停下，而是迎着镜面撞了过去。

巨镜碎裂。追逐她的倒影，也随着那些裂纹消失了。

碎镜中，传来最后两句话。

「也许，这也算是不错的告别吧。」

「……对了，我叫 darksky。」

主角带着颜色走出了教堂。这一次，她记住了那个女孩的名字。

## 游戏中的呈现

- 标题画面为新坠入镜面的主角命名；darksky 的真名不在开场透露。
- 序章分四段，讲述等待、相遇与成为倒影；按 Enter 或点击逐段继续。
- 无色、红色、蓝色、绿色关卡分别承接相助、留恋、含糊的承诺和脚步追近。
- 四关出口之后进入独立追逐段。按 D / → 向右逃跑，可用 Shift 冲刺；撞上前方巨镜时自动击碎镜面。
- 被倒影追上会从追逐入口重试，保留已经找到的颜色。完成告别后才记录整段旅程完成。
